# Battlefield 2042 — Loadouts optimisés, ARMES + VÉHICULES (contenu final, saisons 1-7)

Référence complète de l'arsenal BF2042 en fin de vie (Season 7 "Turning Point", dernières mises à jour de contenu 2024) : les 42 armes All-Out Warfare (base + saisons 1 à 7) + les 19 Vault weapons (armes BF3 / Bad Company 2 utilisables dans le mode principal) + tous les véhicules. Chaque arme a son build "plein potentiel" + ce que tu mets dans les slots alternatifs du menu Plus. Orienté **Conquête / grandes cartes**, équilibrage final (patch 7.3+).

## Méthodologie (comment lire)

- **Déblocage** : les accessoires se débloquent **par kills avec l'arme** (paliers fixes, ~tous les 10-20 kills par slot). Les armes elles-mêmes viennent du niveau de compte (base), des Battle Pass saisonniers (gratuits, débloquables rétroactivement par défis après la saison) et de la collection pour les Vault weapons.
- **4 slots réels** : Optique / **Canon** (le slot regroupe bouches ET canons : suppressors, compensators, muzzle brakes, Extended/Shortened Barrel) / Sous-canon (grips, lasers, bipied, lance-grenades) / **Munitions** (type de balle + taille de chargeur combinés).
- **Système Plus** : tu pré-équipes jusqu'à **4 options par slot** dans ton loadout, et tu changes **en jeu, à la volée** (menu Plus, touche T maintenue). L'optimisation BF2042 = un build principal **+ des alternatives pertinentes dans la roue**. La colonne "Alternative Plus" du tableau = ce que tu mets dans la roue pour basculer selon la situation. Recharge ton chargeur avant de changer de munitions (le swap vide l'arme).
- **Low-zoom vs high-zoom** : au-delà d'un grossissement ~2.5x, l'arme prend un malus de visée (sway, ADS plus lent) et le scope glint apparaît sur les forts zooms de sniper. Reste en 1x-2.5x sur tout ce qui est automatique ; les zooms 4x+ sont pour DMR/bolt.
- Optique 1x : **Fusion Holo / K8 Holo / XDR Holo / 8R Holo** sont équivalents — question de réticule. Je note "Holo 1x" ; mets celui que tu préfères. Les hybrides (**Ghost Hybrid 1.25x**, **MAUL Hybrid 1.5x**) donnent deux réticules commutables.
- Sous chaque tableau, un bloc **quand / comment** comme pour BF4 : "**Build standard**" = comment jouer la colonne Attachement ; "**Plus**" = quand basculer sur les alternatives de la roue. "**Build unique**" = une seule vraie config.

| Accessoire | Effet | Contrepartie |
|---|---|---|
| **Tactical Compensator** | Réduit le recul horizontal | Léger malus de précision hanche |

| **Shortened Barrel** | ADS et hanche nettement meilleurs | Portée/vélocité réduites (CQB only) |
| **BCG Light Grip** | Contrôle vertical en tir soutenu | — |
| **LWG Grip** | Réduit le recul horizontal | — |
| **Cobra Grip** | ADS plus rapide (agilité) | — |
| **Rattlesnake Light Grip** | Précision en mouvement | — |
| **LS-1 / STNR Laser Sight** | Tir à la hanche resserré | Visible par l'ennemi |

### Munitions (le slot le plus important du jeu)

| Type | Effet | Quand |
|---|---|---|
| **Standard Issue** | Équilibré, souvent le plus gros chargeur de base | Défaut fiable |
| **Extended / Drum Mag** | +capacité | Rechargement plus lent — LMG-style |
| **High-Power** | +vélocité, +portée des dégâts | +recul, souvent −capacité → mid/long range |
| **Subsonic** | **Invisible minimap même sans suppressor** | −vélocité/portée → furtif CQB |
| **Armor Piercing (AP)** | Dégâts aux véhicules légers/boucliers | Moins bon TTK infanterie |
| **Close Combat** | Maniement/rechargement plus rapides | Portée réduite |

**Les 3 profils méta à mettre dans ta roue Plus :**
1. **CQB** → Holo 1x + Champion Muzzle Brake (ou Shortened Barrel) + laser + Standard/Drum
2. **Mid-long** → 2.5x-3x + Tactical Compensator/Extended Barrel + BCG + High-Power
3. **Furtif** → Holo 1x + Wrapped Suppressor + Subsonic

## 🔫 Fusils d'assaut

**Méta catégorie** : Champion Muzzle Brake ou Tactical Compensator + BCG Light Grip presque partout ; le vrai choix se joue dans le slot Munitions (High-Power à distance, Drum en rush, Subsonic en furtif). Garde toujours un Holo 1x ET un 2.5x dans la roue Plus.

### M5A3 — S, le pilier du jeu

| Slot | Attachement | Alternative Plus |
|---|---|---|
| Optique | Holo 1x (Fusion) | SHAN 2.5x |
| Canon | Champion Muzzle Brake | Wrapped Suppressor |
| Sous-canon | BCG Light Grip | LS-1 Laser Sight |
| Munitions | High-Power Extended | Standard Drum |

Recul quasi nul, bon TTK, aucune faiblesse : l'ACE 23 de 2042. Dispo dès le début.

- **Build standard** — toutes cartes : full auto jusqu'à ~30 m, rafales de 4-6 balles au-delà avec la High-Power. La 2.5x dans la roue pour les cartes ouvertes.
- **Plus (Drum + laser)** — rush d'objectif Breakthrough : 60 coups, hipfire correct, tu tiens un couloir seul.

# 🚗 VÉHICULES

Même logique de lecture que le fichier véhicules BF4 : colonne "Équipement" = build recommandé, "Alternative" = option situationnelle, puis **quand / comment**. Les déblocages véhicules se font **au score gagné dans le véhicule** ; les meilleurs équipements (APS, TOW, missiles) arrivent en dernier. Depuis la refonte Saison 5, la plupart des véhicules ont des slots séparés conducteur / tireur / sièges d'appui.

### Les contre-mesures à comprendre

| Contre-mesure | Effet | Quand |
|---|---|---|
| **Smoke Discharger / Thermal Smoke** | Casse les locks (missiles, SOFLAM) ; la Thermal bloque aussi la thermique | Défaut solide sol |
| **APS (Active Protection System)** | **Détruit en vol** les projectiles entrants pendant quelques secondes (sauf railgun TOR et tirs à bout portant) | Dès que débloqué — mais il partage son slot avec le Repair System sur les chars |
| **Missile Countermeasure (flares)** | Casse un missile déjà verrouillé/tiré | Obligatoire sur tout ce qui vole |
| **Repair System** | Auto-réparation hors combat | La vraie "contre-mesure" si tu joues solo |

## 🛡️ Char (MBT — M1A5 / T28)

| Slot | Équipement | Alternative |
|---|---|---|
| Primary | HE Shell | MPAT (mixte, tir tendu) / STAFF (feu continu) |
| Secondary | Coax Heavy Machine Gun | Coax LMG |
| Équipement 1 | Thermal Smoke Package | Smoke Discharger |
| Équipement 2 | APS | Repair System (si solo sans soutien) |
| Gunner | TOW Missile | Minigun / HMG |
| Support | Canister Weapon Pod | 60mm Mortar Pod / Rocket Pod |

- **Build standard** — contrôle de zone : HE sur l'infanterie et les véhicules légers, coax HMG pour finir. Déclenche l'**APS quand l'ennemi tire** (il mange l'obus/le missile), pas en préventif — attention, l'APS n'arrête ni le railgun du TOR ni un C5 posé. Le gunner TOW gagne les duels de chars.
- **Variante solo (Repair System)** — sans ingénieur ni gunner : le Repair prime sur l'APS, recule derrière un couvert dès 50 % de vie et répare.
- Ne pousse jamais seul au milieu : les C5 (Bolte, Mackay/Sundance) sont la première cause de mort d'un char 2042. Garde de la distance et un champ de tir dégagé.

## Rappel rapide

- **Conquête 128 / grandes cartes** : M5A3 ou RM68 High-Power + 2.5x dans la roue, SVK ou DXR-1 en overwatch, G57 en secondaire. Véhicules : M1A5 APS, Wildcat si l'air domine, Nightbird si tu sais voler.
- **Breakthrough / objectifs serrés** : PP-29, SCZ-3 ou MCS-880 + Drum/laser, BSV-M pour tenir un angle sans apparaître sur la map. Avancys posée en défense. CAV-Brawler ou MAV pour pousser en équipage.
- **Close maps (Stadium, Redacted, intérieurs)** : K30/MP9 hanche + laser, 12M Auto, AM40. Profil Plus furtif (Wrapped + Subsonic) prêt dans la roue.
- **Débutant** : M5A3 + Champion Muzzle Brake + BCG + Extended — l'arme qui t'apprend le jeu. PBX-45 en SMG, SWS-10 en sniper, LATV4 pour te déplacer. Débloque vite le G57.
- **Le réflexe 2042** : ta roue Plus est ton loadout. Un build principal + un profil close + un profil range + un profil furtif = tu n'es jamais dans la mauvaise configuration.
- **Priorité déblocage véhicules** : APS partout où il existe > TOW/missiles guidés > Thermal Smoke. En l'air : flares d'abord, Repair System toujours.
